# Sterbenz Lemma — Formal Verification (frama-c → PVS)

Formal proof that floating-point subtraction `x - y` is exact (no rounding error)
when `y/2 ≤ x ≤ 2y`.

## Pipeline

```
Sterbenz.c (ACSL-annotated C)
    │
    ▼  frama-c / Jessie
    │
    PVS proof obligations
    │
    ▼  PVS prover
    │
    Machine-checked proof
```

## Files

- `Sterbenz.c` — C source with ACSL contract (`requires`, `ensures`)
- `Sterbenz_Jessie_program_*.pvs` — PVS obligations generated by frama-c/Jessie
- `Sterbenz_Jessie_program_*.prf` — PVS proof
- `Sterbenz_fixed_round.pvs` — Generic floating-point Sterbenz theorem (parametric over radix β)
- `Sterbenz_fixed_round.prf` — Proof
